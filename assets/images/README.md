# Service illustrations

Six original SVG illustrations generated locally for Waviq, drawn directly with vector shapes and text. No stock artwork, external logos, identifiable people, scripts, external resources, fonts or tracking are embedded. Colours follow the existing navy-and-teal site palette.

- `messaging-automation.svg`: shared by SMS, WhatsApp, Messenger and custom automation.
- `crm-lead-management.svg`: shared by CRM and lead management.
- `analytics-dashboard.svg`: reporting cards and sample charts.
- `responsive-website-development.svg`: desktop and mobile layouts.
- `ecommerce-storefront.svg`: products and a cart.
- `content-blog-writing.svg`: shared by content and blog writing.

All conversations, records, metrics, products and article content are fictional. These are conceptual illustrations, not finished Waviq products or real customer results. Each placement includes the visible HTML caption “Illustrative example”; retain that caption when reusing an asset.

Each SVG has a 640 × 420 viewBox and explicit dimensions. HTML supplies descriptive alt text and proportional responsive sizing. All current placements are below the fold and lazy-loaded; omit loading="lazy" if moving an illustration above the fold. The original logo.png is unchanged.
